# 全人类智慧决策顾问 (Ancient Wisdom Advisor)

用全人类几千年攒下的智慧 + 现代最前沿的决策科学，为你的具体难题找方向。

不是算命，不是鸡汤，不是掉书袋——是把经过千年验证的策略逻辑，和现代科学的决策工具，一起翻译成你现在就能用的动作。

---

## 为什么做这个

遇到人生难题的时候，我们往往靠直觉、靠情绪、靠朋友说的几句话来做决定。但人类几千年攒下的智慧——从孙子兵法到斯多葛学派，从易经到决策科学——其实早就把这些问题研究透了。

这个Skill做的事：把这些智慧整理成一套可操作的决策流程，遇到具体问题时，直接调用对应的智慧给你方向。

---

## 功能特点

- **全人类智慧覆盖**：中国儒释道兵、西方哲学、宗教智慧、现代决策科学
- **问题分类精准**：6类问题（竞争博弈/心态内耗/时机趋势/人际说服/管理复杂/成长破圈），每类对应一套策略库
- **小决策快答，大决策深析**：一句话问题三句话搞定；重大决策走6步闭环，每一步都引用经典智慧
- **压力测试**：给完建议后，自动反向挑毛病，防止自嗨
- **反脆弱设计**：默认小步试错，不鼓励all in

---

## 怎么用

把这个Skill放到你的AI agent的skills目录下，遇到难题时直接描述你的处境，它会自动触发。

### 输入示例

> "我现在纠结要不要辞职创业，工作3年了，攒了20万存款，想听听建议。"

### 输出示例

```
## 【局诊断】
两三句话说清本质。

## 【策略库】
### 策略一：<名称>
- 出处：<哪本经典/哪个决策工具>
- 核心逻辑：<大白话解释>
- 为什么适合你：<对应到你的处境>

## 【行动清单】
1. 这周第一个动作（具体到能立刻执行）
2. 下一步怎么走
3. 要避开的坑

## 【注意事项】
1. ...
```

## 适用场景

✅ 人生决策（转行/创业/订婚/阶级跨越）
✅ 竞争策略（职场竞争/谈判/抢资源）
✅ 心态内耗（焦虑/纠结/想不开）
✅ 人际冲突（矛盾/说服/向上管理）
✅ 时机判断（现在动还是等等）
✅ 成长破圈（转行/学新东西/换赛道）

---

## 不适用场景

❌ 医疗诊断、法律意见、心理危机干预
❌ 具体投资建议（买什么股票/基金）
❌ 技术问题（怎么写代码/怎么修电脑）
❌ 简单事实查询

> 遇到以上场景，这个Skill会提醒你去找专业人士。

## 设计原则

1. **不要硬套**——不匹配就宁可不提
2. **用大白话**——术语第一次出现要解释
3. **语气像朋友**——不说教，给建议
4. **行动要具体**——不说"调整心态"，说"今晚8点打开BOSS直聘投5份简历"
5. **情绪优先**——用户崩溃时先共情，再分析
6. **留退出选项**——有时候最好的策略是退出游戏
